# OSIS & MPK SMKN 1 Banyumas 🎓

Website resmi Organisasi Siswa Intra Sekolah (OSIS) dan Majelis Perwakilan Kelas (MPK) SMKN 1 Banyumas tahun ajaran 2024/2025.

## 📋 Deskripsi

Website ini merupakan platform informasi dan komunikasi resmi OSIS & MPK SMKN 1 Banyumas yang menyajikan informasi tentang:
- Profil dan struktur organisasi
- Program kerja dan kegiatan
- Galeri dokumentasi kegiatan
- Berita terkini seputar OSIS & MPK
- Informasi kontak dan media sosial

## ✨ Fitur Utama

- **7 Halaman Lengkap**: Beranda, Tentang, Program Kerja, Pengurus, Galeri, Berita, dan Kontak
- **Desain Modern**: Menggunakan kombinasi warna merah, emas, dan netral yang elegan
- **Responsive**: Tampilan optimal di desktop, tablet, dan mobile
- **Animasi Interaktif**: Scroll animations dan hover effects
- **Navigasi Intuitif**: Menu navigasi yang mudah digunakan dengan hamburger menu untuk mobile
- **Statistik Organisasi**: Menampilkan data program kerja, anggota aktif, dan ekstrakurikuler

## 🛠️ Teknologi yang Digunakan

- **HTML5** - Struktur markup semantic
- **CSS3** - Styling dengan custom properties (CSS variables)
- **JavaScript** - Interaktivitas dan animasi
- **Google Fonts**:
  - Playfair Display (heading)
  - DM Sans (body text)
  - Bebas Neue (accent text)
- **Font Awesome 6** - Icon library

## 🚀 Cara Menjalankan

Website ini adalah static site yang dapat dijalankan langsung tanpa server:

1. **Clone atau download** repository ini
2. **Buka file** `index.html` di browser favorit Anda
3. Atau gunakan **Live Server** extension di VS Code untuk pengalaman development yang lebih baik

```bash
# Menggunakan Python Simple HTTP Server (opsional)
python -m http.server 8000

# Atau menggunakan Node.js http-server (opsional)
npx http-server
```
